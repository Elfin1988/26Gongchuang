| 2430 线色 | 功能           | 选用引脚 | 配置 |
| --------- | -------------- | -------- | ---- |
| 黄线      | **FG** 转速反馈 | **PD11** | **EXTI11** 上升沿输入，带上拉 |
| 白线      | **PWM** 调速    | **PD12** | **TIM4_CH1** PWM 输出 |
| 橙线      | **DIR** 正反转  | **PD13** | 普通 GPIO 输出 |

这组三个脚都在主控右侧上半区，比原来的 `PA0 / PD1 / PD2` 更集中一些。
