**四个底盘电机的引脚分配**

* PWM 四路：
  * **PA6** → **PWMA / TIM3_CH1**
  * **PA7** → **PWMB / TIM3_CH2**
  * **PB0** → **PWMC / TIM3_CH3**
  * **PB1** → **PWMD / TIM3_CH4**
* 方向八路：
  * **PE0** → **AIN1**
  * **PE1** → **AIN2**
  * **PE2** → **BIN1**
  * **PE3** → **BIN2**
  * **PE4** → **CIN1**
  * **PE5** → **CIN2**
  * **PE6** → **DIN1**
  * **PE7** → **DIN2**
